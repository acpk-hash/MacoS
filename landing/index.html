AgentBoard 是一个本地优先的 Agent 任务工作台——像管理项目卡片一样管理你的 AI 任务，实时看到每一步文件修改。

⚡

类 Codex 聊天工作区

与 Agent 对话的同时，实时预览每个文件的创建、修改与删除——再也不用猜 Agent 在做什么。

📋

看板管理多任务

用列与卡片组织多个并行任务，状态一目了然。切换任务无需关闭当前上下文。

💬

直连 API 对话

内置 ChatGPT 级聊天界面：流式输出、图片与文件附件、多会话管理、模型随时切换，配置一次即可使用。

🎨

图像生成工作台

输入描述即出图，画廊网格管理全部作品，一键另存到本地。视频生成模式已就绪，模型开通即可用。

🛠️

Trae 式代码工作区

选一个文件夹即刻开工：左侧文件树、中间 Monaco 编辑器、右侧 AI 对话直接改文件并展示 inline diff。可连 SSH 远程编辑、挂载 MCP 工具与技能，Claude-Code 风格进度条实时显示 token 消耗。

🧮

超越网页版的对话

数学公式渲染、代码高亮、真实可点的搜索链接；结果一键导出为 Markdown 或自包含 HTML，离线也能看。

🔌

多服务商随心切换

配置任意 OpenAI 兼容服务商与自己的 API Key，下拉即切模型、切账号；密钥仅存本机凭据管理器，永不上传。

🗂️

运行沉淀可回溯

做过的每一次 agent 运行、用过的技能都沉淀在本地，可检索、可回放、一键复用，token 与文件改动尽收眼底。

⚙️

内置 Agent 引擎

自研引擎随安装包开箱即用，无需再装任何命令行工具；回复逐字流式输出，比子进程模式更快更稳。

📱

手机实时同步

注册一个账号，手机 App 实时看到电脑上的任务进度与对话内容；躺在沙发上派发新任务、一键验收，通道全程加密。

🔒

数据可控

任务历史、文件快照全在本机；手机同步只传必要内容，API 密钥永不上传，同步默认关闭。
