FAQ

常见问题

关于本地运行、数据安全、模型接入与安装的常见疑问。

AgentBoard 是什么？

一个本地优先的 AI Agent 工作台。它把对话、看板任务、代码工作区、图像生成、文档可视化与科研流水线整合到一个桌面应用里，自研引擎随安装包内置，装完即用。你在真实的本地文件上工作，全过程可见、可控、可回溯。

免费吗？

应用本身免费下载使用，当前为 Beta。调用大模型的费用取决于你自己配置的 API 服务商——你用自己的 Key，按你选择的服务商计费，AgentBoard 不在中间加价。

我的数据安全吗？

任务历史、文件快照与对话记录都保存在本机。手机同步默认关闭；即使开启，也只传递必要的任务与对话内容，且通道加密。API 密钥始终存于本机凭据管理器，永不上传。

需要另外安装命令行工具吗？

不需要。Agent 引擎已随安装包内置，装完即用，无需你再单独安装任何 CLI、运行时或外部依赖。这也是安装包偏大（约 300MB）的原因。

支持哪些模型？

支持任意 OpenAI 兼容的服务商。你填入自己的服务地址与 API Key，就能在下拉里切换模型与账号。用哪个模型、走哪个中继完全由你决定。

手机怎么同步？

在桌面端与手机 App 登录同一个账号即可。手机会实时看到电脑上的任务进度与对话内容，你也可以从手机远程派发新任务、一键验收。通道全程加密，同步默认关闭、按需开启。

安装时 SmartScreen 提示怎么办？

安装包目前未做代码签名，Windows 首次运行可能弹出「Windows 已保护你的电脑」。这是正常现象：点击「更多信息」，再点「仍要运行」即可继续安装。你也可以先用同目录的 .sha256 文件校验安装包完整性。

支持 SSH 远程和 MCP 吗？

支持。代码工作台可连接 SSH 进行远程编辑，也可以挂载 MCP 工具与技能，让 Agent 调用你需要的外部能力。

系统要求是什么？

桌面端为 Windows x64（v0.9.3，安装包约 300MB，内置引擎）。手机端为 Android 7.0 及以上（v1.0.0 签名 APK）。安装后即可本地运行，接入模型时需要联网访问你配置的 API 服务商。
