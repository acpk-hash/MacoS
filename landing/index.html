Tutorial

使用教程

从安装到进阶功能，逐步上手 Iris 的全部能力。

快速上手：安装与首次使用

1. 从下载页获取最新安装包（Windows .exe / Android .apk）。2. 双击运行安装程序，如遇 SmartScreen 提示，点击「更多信息」→「仍要运行」。3. 安装完成后启动 Iris，点击左上角「打开项目」选择一个本地项目文件夹。4. 在中间输入框用一句话描述任务（如「帮我给 app.ts 加上超时重试」），按回车发送。5. 观察 Agent 在 Timeline 中逐步读文件、改代码、跑命令，右侧面板显示改动文件。

配置 API Key 与服务商

1. 点击左下角齿轮图标进入「设置」。2. 在「模型服务商」区域点击「添加服务商」。3. 填入服务商名称、base_url（如 https://api.openai.com/v1）和 API Key。4. 点击「测试连接」确认可用。5. 返回主界面，在顶部模型选择器中切换到刚添加的服务商和模型。API Key 保存在 Windows 凭据管理器中，不落盘、不上传。

深度研究：AI 自动调研

1. 在左侧导航栏点击「研究」页面。2. 在输入框中输入你的研究问题（如「2024 年 Rust vs Go 在微服务领域的优劣对比」）。3. 点击「开始研究」，AI 将自动执行五个阶段：问题分解 → 广域搜索 → 深度阅读 → 交叉验证 → 综合报告。4. 每个阶段的进度和中间结果实时可见。5. 研究完成后，可导出带来源引用的完整报告。

定时任务：自动化 AI 工作

1. 在左侧导航栏点击「定时」页面。2. 点击「创建任务」，填入任务名称和提示词。3. 设置调度计划：选择每小时 / 每天 / 每周 / 自定义 Cron 表达式。4. 可选配置通知推送（桌面通知 / Webhook）。5. 启用任务后，系统会按计划自动执行，执行历史和结果在任务详情页查看。

模型盲测：对比评估模型

1. 在左侧导航栏点击「盲测」页面。2. 选择 2-4 个已配置的模型参与对比。3. 输入测试提示词，点击「开始盲测」。4. 系统同时向所有模型发送请求，结果以匿名方式（模型 A / B / C / D）展示。5. 阅读结果后进行盲投票，选出你认为最好的回答。6. 投票后揭晓各模型身份，结果计入 ELO 排行榜。

向量检索与 RAG 对话

1. 在左侧导航栏点击「检索」页面。2. 点击「构建索引」，选择要索引的文档目录或上传文件。3. 索引完成后，可使用三种搜索模式：关键词搜索（精确匹配）、语义搜索（向量相似度）、混合搜索（两者结合）。4. 点击搜索结果旁的「注入对话」按钮，将检索到的上下文自动注入 AI 对话，实现 RAG 增强问答。

Webhook 集成

1. 进入「设置」→「Webhook」页面。2. 点击「创建端点」，填入目标 URL。3. 设置签名密钥（Secret），系统使用 HMAC-SHA256 对每次推送签名。4. 勾选要订阅的事件类型：任务完成、新消息、研究结果、定时任务执行等。5. 点击「测试推送」验证端点连通性。6. 保存后，系统事件将自动推送到你的端点。

飞书 / 企业微信远程控制

1. 进入「设置」→「聊天绑定」页面。2. 选择飞书或企业微信，点击「生成绑定码」。3. 在飞书 / 企业微信中找到 Iris 机器人，发送「绑定 XXXXXX」（替换为你的绑定码）。4. 绑定成功后，你可以直接在聊天中向 Iris 发送指令，桌面端会同步执行并返回结果。支持文字指令、查看任务状态、接收完成通知。

手机同步与远程控制

1. 从下载页获取移动版安装包（Android / HarmonyOS / iOS 均可）。2. 使用与桌面端相同的账号登录，登录即自动连接，无需手动绑定。3. 在「远程控制」页面可以：实时查看任务进度与执行过程、远程创建/分派/接受任务、浏览桌面端工作目录文件、发送查看文件请求、继续多轮对话。4. 所有数据通过 WebSocket 实时同步，确保移动端与桌面端状态一致。

FAQ

常见问题

关于本地运行、代码安全、模型接入与安装的常见疑问。

Iris 是什么？

一个本地运行的 AI 编码 Agent 桌面应用。打开项目文件夹、描述任务，内置 Agent 就在你的电脑上真实读写代码、执行命令、多步完成任务。界面是熟悉的三栏：左边会话列表，中间流式对话 Timeline 与输入框，右边会话信息与改动文件。

免费吗？

应用本身免费下载使用，当前为 Beta。调用大模型的费用取决于你自己配置的 API 服务商——你用自己的 Key，按你选择的服务商计费，Iris 不在中间加价。

我的代码会上传到你们的服务器吗？

不会。Iris 全部在本机运行，你的代码不经过我们的服务器。只有 Agent 调用模型 API 时，相关上下文才会发送给你自己配置的模型服务商——用哪家服务、发给谁，完全由你决定。

需要另外安装 Node、Python 或命令行工具吗？

不需要。安装包内置 pi 编码 Agent 运行时与自包含 Node 环境，装完即用，无需再安装任何 CLI、运行时或外部依赖。

需要什么 API Key？支持哪些模型？

任意 OpenAI 兼容的服务商或中转都可以：在设置里填入服务地址（base_url）与你自己的 API Key，即可切换模型。密钥保存在 Windows 凭据管理器中，不落盘、不上传。

Agent 正在运行时能干预吗？

可以。输出是逐字流式的，你可以随时插话（steer）修正方向，把新要求排队追加，或者一键中断。每一步工具调用都显示在 Timeline 里，可展开查看细节。

安装时 SmartScreen 提示怎么办？

安装包目前未做代码签名，Windows 首次运行可能弹出「Windows 已保护你的电脑」。这是正常现象：点击「更多信息」，再点「仍要运行」即可继续安装。你也可以先用同目录的 .sha256 文件校验安装包完整性。

系统要求是什么？

桌面端支持 Windows x64 与 macOS（v0.14.0）。移动端支持 Android 7.0+、HarmonyOS (鸿蒙) 4.0+ 与 iOS 16+。鸿蒙版与 Android 版同源构建，APK 通用。应用本身在本地运行；Agent 调用模型时需要联网访问你自己配置的 API 服务商。
