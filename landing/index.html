把 AI Agent 装进看板
本地运行，数据不出机

AgentBoard 是一个本地优先的 Agent 任务工作台——像管理项目卡片一样管理你的 AI 任务，实时看到每一步文件修改。

⚡

类 Codex 聊天工作区

与 Agent 对话的同时，实时预览每个文件的创建、修改与删除——再也不用猜 Agent 在做什么。

📋

看板管理多任务

用列与卡片组织多个并行任务，状态一目了然。切换任务无需关闭当前上下文。

💬

直连 API 对话

内置 ChatGPT 级聊天界面：流式输出、图片与文件附件、多会话管理、模型随时切换，配置一次即可使用。

🎨

图像生成工作台

输入描述即出图，画廊网格管理全部作品，一键另存到本地。视频生成模式已就绪，模型开通即可用。

🗺️

工作流执行画布

Agent 干活的每一步——回复、命令、文件修改——都变成画布上的节点与时间轴，执行过程一眼看穿。

🔒

数据不出本机

所有任务历史、文件快照均存储在本地。无云端同步，无账号，无订阅。自己的数据自己掌控。
