# AgentBoard 二次元设计系统 v0.6(Sakura Dream)

> 用户方向(2026-07-07):UI 要二次元风格(番剧/galgame 质感),网页+桌面+手机统一。取代当前偏工程感的暗色 UI。

## 一、气质关键词
柔和、梦幻、可爱但不幼稚;深色底 + 粉紫天蓝霓光点缀;圆角、玻璃拟态、柔和发光;少量星光/闪粒点缀(克制,别糊)。参考:番剧设置菜单、galgame 存档界面、Pixiv 暗色、崩坏/明日方舟 UI 的柔光感。

## 二、色板(硬性,三端统一用这些值)

### 底色(深色但不纯黑,偏深紫蓝)
- `--bg`: #14121f(最底)
- `--surface`: #1e1b2e(卡片底)
- `--surface-2`: #272338(悬浮层/输入)
- `--elevated`: #2f2a44(弹层)
- `--border`: rgba(255,255,255,0.08)(玻璃描边)
- `--border-strong`: rgba(180,150,255,0.22)

### 点缀色(霓光,pastel)
- `--sakura`(主粉): #ff7fbf
- `--lavender`(薰衣草): #b58fff
- `--sky`(天蓝): #7fb0ff
- `--mint`(薄荷): #7fe7c4
- `--gold`(暖金): #ffd88f
- `--coral`(珊瑚/错误): #ff8b9a

### 主渐变
- `--grad-primary`: linear-gradient(135deg, #ff7fbf 0%, #b58fff 50%, #7fb0ff 100%)
- `--grad-soft`(大背景弥散光): radial-gradient 顶部粉、底部蓝,极低透明度叠在 --bg 上
- 按钮/高亮描边/logo/进度条用 --grad-primary。

### 文字
- `--text`: #ece8fb
- `--text-muted`: #a49dc7
- `--text-dim`: #6f6a8f

### 语义状态(pastel,映射到看板/任务/工具)
- 运行中 running → --sky;完成 done → --mint;待办 todo → --lavender;失败 failed → --coral;审阅 awaiting → --gold。
- 状态点用实心圆 + 同色低透光晕(box-shadow 0 0 8px 该色/40%)。

## 三、形状与质感
- 圆角:卡片 18px、弹层 20px、按钮 12px、输入 12px、chip 全圆(999px)、头像/图标容器 14px。
- 玻璃拟态:surface 上叠 `background: rgba(30,27,46,0.72); backdrop-filter: blur(14px); border:1px solid var(--border)`;顶部 1px 内高光 `inset 0 1px 0 rgba(255,255,255,0.06)`。
- 发光:主按钮/激活项 `box-shadow: 0 4px 20px rgba(255,127,191,0.28)`;hover 上浮 translateY(-1px)+ 加深光晕。
- 分隔线用极淡渐变而非实色。
- 背景:全局 --bg 上叠 --grad-soft 弥散光 + 可选极淡星点纹理(SVG data-uri,透明度<5%)。

## 四、字体
- 拉丁/数字:圆润无衬线——优先 "Varela Round"/"Baloo 2"/"M PLUS Rounded 1c"(可用 Google Fonts 或打包 woff2;离线优先打包一款,如 M PLUS Rounded 1c Regular/Bold)。回退 ui-rounded, system-ui。
- 中文:保持 "PingFang SC","Microsoft YaHei";标题可加大字重与字间距。
- 标题略放大 + 渐变文字(background-clip:text)用于 hero/大标题,正文正常色。

## 五、吉祥物 & 图标
- 吉祥物:一个可爱的小机器人/星灵 SVG(圆脑袋、大眼 `[•‿•]`、粉蓝配色、头顶星芒),用于:空态插画、加载态、logo 旁、手机启动页。提供 SVG 组件 `<Mascot mood="idle|thinking|happy|sad" />`(不同表情/微动效)。
- 图标:圆润线性图标(lucide-react 已在用则统一 strokeWidth 1.75、圆头);激活态图标用渐变或 --sakura。

## 六、动效(克制)
- hover/active 用 150-200ms ease 过渡;卡片上浮微光。
- 流式打字光标、进度条流光(渐变滑动)、加载用吉祥物 thinking 微动。
- 关键操作成功可闪一下星光(sparkle),别频繁。
- 尊重 `prefers-reduced-motion`。

## 七、落地范围与顺序
1. **桌面(主):** Tailwind 主题扩展(把上面色值写进 `tailwind.config`)+ `index.css` 基础层(玻璃/发光工具类、字体、背景弥散)+ 共享组件(Button/Card/Chip/StatusDot/Mascot/GlassPanel)+ 全站页面改皮(Layout 侧栏、看板、对话、生成、工作台、沉淀、设置)。
2. **落地页:** 纯 HTML/CSS 按同色板/渐变/圆角/字体重做,加 hero 吉祥物与霓光背景。
3. **手机:** RN 主题(同色值),导航与各屏改皮,启动页放吉祥物。

## 八、约束
- 不牺牲可读性:正文对比度达标(text on surface ≥ 4.5:1);霓光只用于点缀/描边/高亮,不铺满大面积文字底。
- 暗色为默认且唯一(本期不做浅色)。
- 三端色值以本文件为准,禁止各自发挥导致漂移。
