## 设计语言 token(严格采用)

### 颜色
- `--bg`: #0b1020(页面底,深藏青)
- `--surface`: #131b2f(卡片/面板)
- `--surface-warm`: #182343(强调面/hero 预览面板)
- `--border`: #293653;`--border-soft`: #1e2a43
- `--accent`: #60a5fa(蓝,主按钮/链接/eyebrow/高亮);hover 更深、active 再深
- `--fg`: #f8fafc(主文字);`--fg-2`: #cbd5e1;`--muted`: #8ea0b8(次要)
- 语义:success #22c55e、warn #fbbf24、danger #fb7185
- 微妙渐变:accent 相关的极低透明度径向光(顶部)可点缀,但整体克制、深色为主。

### 字体
- 正文/标题:`Inter, system-ui, sans-serif`(用 fonts.loli.net 引入 Inter;失败回退系统)
- 等宽:`"JetBrains Mono", ui-monospace, Menlo, monospace`——用于版本号、SHA256、代码感的小标签(科技感来源)。
- 标题字距 `-0.02em`,line-height 1.05;Hero h1 clamp 到 ~64px;lead 20px muted。

### 尺寸/圆角/阴影
- 圆角:sm 8 / md 12 / lg 20 / pill 9999
- 间距刻度:4/8/12/16/20/24/32/48
- 阴影:raised `0 24px 72px rgba(0,0,0,.36)`;ring `0 0 0 1px var(--border)`;focus `0 0 0 4px rgba(96,165,250,.28)`
- 字号刻度:xs12 sm13 base15 lg17 xl22 2xl32 3xl48 4xl66

### 组件/构图模式
- **eyebrow**:小号(12px)、大写、字重 750、accent 蓝——放在每个区块标题上方。
- **Hero**:两列(左叙事文案 + CTA 按钮;右一个 `panel` 预览面板,里面可放产品要点/mini 表单/统计),窄屏堆叠。
- **button**:min-height 44、圆角 md、字重 750;primary=accent 底白字;secondary=surface 底描边。
- **panel/card**:border + radius + surface 底;卡片网格三列(minmax 0,1fr),gap 14;hover 抬升 + 描边转亮 + raised 阴影。
- **chip**:pill 描边、muted 字,用于标签/特性小点。
- **metric**:大数字(30px 粗)+ muted 说明,用于展示统计/亮点。
- section 纵向间距桌面 96 / 平板 68 / 手机 48。
