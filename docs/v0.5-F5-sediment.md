# F5 设计:Hermes 式 agent/skills 本地沉淀与可视化

> 用户方向(2026-07-07):参考 Hermes 内核,把执行过的 agent 运行与 skills 内容沉淀到本地,做可视化展示。

## 一、理念

把"用完即弃"的 agent 运行变成**可回顾、可检索、可复用**的本地资产库。用户能看到"我过去让 AI 做过什么、用了哪些技能、花了多少 token、改了哪些文件",并能一键重开/复用。这是产品的记忆层。

## 二、数据都已就位(前面几步的副产品)

| 来源 | 表 | 内容 |
|---|---|---|
| codex 看板任务 | `tasks` / `sessions` / `events` / `file_changes` | 每个任务的会话、事件流、文件改动 |
| pi 工作台 | `workbench_sessions` / `workbench_entries` / `workbench_stats` | 每次工作台会话的条目、token 统计、export_html 路径 |
| 直连对话 | `chat_sessions` / `chat_messages` | 聊天历史 |
| 生成 | `gen_media` | 图像/视频产物 |
| skills | pi `--skill` 目录 / codex skills(`~/.codex`) | 已安装/可用技能清单 |

F5 基本是**聚合 + 呈现**,几乎不需要新的采集逻辑;pi 的 `export_html` 和 workbench_entries 落库就是为此铺的。

## 三、产品形态:「沉淀」库页面

侧边栏新增顶层组「沉淀」(或并入现有导航),含两个视图:

### 1. 运行历史(Runs)
- 统一时间线/卡片墙:把 codex 任务、pi 工作台会话、(可选)重要对话合并按时间倒序展示。
- 每张卡:类型徽章(看板/工作台/对话)、标题、工作目录、模型、token 消耗、文件改动数、时长、状态。
- 筛选:按类型/模型/时间/工作目录/关键词全文检索(SQLite FTS 或简单 LIKE)。
- 点开详情:复用已有的展示——工作台会话复用 Workbench 的只读回放(从 workbench_entries 重建输出流)或直接打开 export_html;codex 任务复用现有会话/事件展示。
- 操作:**复用**(以同样的工作目录+模型重开一个工作台会话,预填最初 prompt)、导出 HTML、删除。

### 2. 技能库(Skills)
- 列出可用 skills(来源:pi 的 skills 发现 + codex skills 目录),每个显示名称、描述、来源路径、被使用次数(从历史里统计引用)。
- 支持启用/禁用、查看内容、"在工作台里用这个技能开一轮"。
- 后续可接 marketplace(搜索下载),本期先做本地已有技能的沉淀展示。

## 四、技术实现

### Rust
- `src-tauri/src/sediment.rs`(只读聚合,不新增采集):
  - `sediment_runs{filter}` → 合并 tasks + workbench_sessions(+可选 chat_sessions)为统一 `RunSummary{id,kind,title,cwd,model,tokens,files_changed,duration,status,created_at}`,排序分页。
  - `sediment_run_detail{kind,id}` → 取该运行的完整条目(workbench_entries / events)。
  - `sediment_search{query}` → 跨表关键词检索。
  - `sediment_skills()` → 扫描 pi/codex 技能目录,返回 `{name,description,source,path,use_count}`(use_count 从历史统计,拿不到就 0)。
  - `sediment_reuse{run_id}` → 返回重开工作台所需参数(cwd/model/首条 prompt),前端据此调 workbench_open + workbench_prompt。
- 不改现有采集路径;只读现有表。skills 扫描做成容错(目录不存在返回空)。

### 前端
- `src/pages/Sediment.tsx`(Runs + Skills 两 Tab)+ `src/stores/sedimentStore.ts`。
- 复用现有卡片/详情/diff 组件;运行详情优先复用 Workbench 的只读渲染。
- 路由 `/sediment`,侧边栏加入口。

## 五、范围与非目标(本期)
- 本期:本地已有数据的聚合、检索、回放、复用;本地已有 skills 的展示与"用它开一轮"。
- 非目标(后续):skills 在线市场搜索下载、跨设备沉淀同步(可接 F6 服务器)、AI 对沉淀的二次总结。
- 依赖:F4(workbench_entries 数据)已完成;可在 F4c 之后、与 F6 并行或串行。
