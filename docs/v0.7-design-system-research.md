# AgentBoard 蓝白科研设计系统 v0.7(Research / Academic）

> 用户方向(2026-07-08):放弃二次元,全局换成**蓝白色科研风**(论文/科研工具质感)。三端统一。取代 v0.6 的二次元暗色主题。

## 一、气质
干净、克制、专业;浅色(白/浅灰蓝)底 + 蓝色主色 + 细描边 + 柔和阴影(非发光);像 Overleaf / Notion / 学术仪表盘 / 论文工具。信息密度友好,大量留白,清晰字体。**从暗色翻成浅色**——这是核心变化。

## 二、色板(硬性,三端统一;浅色主题)

### 底与面(浅)
- `--bg`: #f7f9fc(页面底,极浅蓝灰)
- `--surface`: #ffffff(卡片/面板)
- `--surface-2`: #f1f4f9(次级面/输入底/hover)
- `--elevated`: #ffffff + 阴影(弹层)
- `--border`: #e2e8f0(细描边)
- `--border-strong`: #cbd7e6

### 主色(蓝)
- `--primary`: #2563eb(blue-600,主按钮/链接/激活)
- `--primary-hover`: #1d4ed8
- `--primary-tint`: #eff4ff(浅蓝底,选中/高亮背景)
- `--primary-ring`: rgba(37,99,235,0.35)(聚焦环)

### 文字(深色字,浅底上)
- `--text`: #1e293b(slate-800,正文)
- `--text-muted`: #475569(slate-600)
- `--text-dim`: #94a3b8(slate-400,占位/次要)
- 链接:`--primary`,hover 下划线。

### 语义(科研清爽,非 pastel)
- 信息/运行 running → #2563eb;成功 done → #16a34a;警告 awaiting → #d97706;错误 failed → #dc2626;待办 todo → #64748b。
- 状态用实心小圆点或标签,配 `--primary-tint` 类的浅色底徽章,不用光晕。

## 三、形状与质感(比二次元更利落)
- 圆角:卡片/面板 10-12px、按钮 8px、输入 8px、chip 6px、图标容器 8px。整体比二次元收敛、更"工具感"。
- 阴影(柔和,非发光):卡片 `0 1px 3px rgba(15,23,42,0.06), 0 1px 2px rgba(15,23,42,0.04)`;弹层 `0 8px 24px rgba(15,23,42,0.12)`;hover 抬升到中等阴影。
- 描边:1px `--border`;强调/选中用 `--primary` 或 `--primary-tint` 底。
- 背景:纯 `--bg`,可选极淡网格/点阵(opacity<3%)增科研感;不要弥散霓光。
- 分隔线:实色 `--border` 细线。

## 四、字体
- UI:无衬线,清晰专业——"Inter" + 中文 "Source Han Sans SC"/"PingFang SC"/"Microsoft YaHei"。数字用 tabular-nums。
- 代码/公式上下文:等宽 "JetBrains Mono"/"Cascadia Code"/ui-monospace。
- 论文/PPT 正文可选衬线("Source Serif"/"Noto Serif SC")营造学术感——仅用于内容渲染区,UI 仍无衬线。
- 标题:字重 600-700,字距略紧;不要渐变文字(科研风用纯 `--text` 或 `--primary`)。

## 五、Logo(欧拉 φ)
- 品牌标:**欧拉函数 φ(phi)** 字形——一个圆角方块(蓝 `--primary` 实色或 #2563eb→#3b82f6 轻渐变)内置白色 φ 符号,简洁。
- 交付:`src/components/Logo.tsx`(SVG 组件,可调尺寸)+ favicon/应用图标(`icons/` 更新为 φ 蓝白版,tauri 与 landing 用)+ 手机启动图标。
- φ 形态:竖线穿过椭圆(标准 φ),线条圆头、粗细均匀、居中留白。

## 六、Monaco 与暗→浅切换(关键)
- 全站从暗色翻浅色:所有 `bg-surface/bg-bg` 是浅色,文字是深色。改皮时务必逐页检查对比度与"黑底残留"。
- **Monaco 编辑器**:自定义 light 主题 `agentboard-light`(底 #ffffff/#f8fafc、当前行浅蓝、关键字蓝、字符串绿),取代之前的暗色 `agentboard-dark`。
- 图表/画布/终端输出同步翻浅。

## 七、动效(克制)
- hover/active 150ms;卡片抬升阴影;聚焦显示 `--primary-ring`。无星光、无渐变流光。尊重 prefers-reduced-motion。

## 八、落地范围与顺序(H0)
1. 桌面:Tailwind 主题改浅色 token + index.css 基础层(浅底、阴影工具类、字体、聚焦环)+ 共享 ui 组件重做为蓝白(Button/Card/Chip/StatusDot/Logo;移除 Mascot 或改为极简科研插画/留空态用简洁图标)+ 全站页面翻浅色皮(Layout/看板/对话/生成/工作台含 Monaco light/沉淀/设置)。
2. 落地页:改蓝白科研风 + φ logo。
3. 手机:RN 浅色主题。

## 九、约束
- 浅色为默认且唯一(本期不做暗色切换)。对比度:正文 slate-800 on 白 ≥ 7:1。
- 三端色值以本文件为准。改皮只换视觉不改逻辑。无 BOM UTF-8。
- 吉祥物 Mascot 退场(二次元产物);空态改用简洁线性图标 + 说明文字(科研风)。
