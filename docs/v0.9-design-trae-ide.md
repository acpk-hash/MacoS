# AgentBoard 桌面 UI 重做:Trae 风格专业 IDE(v0.9）

> 用户方向(2026-07-11):现桌面 UI「过于 AI 化」(模板感/廉价 AI 生成感)。要改成**类 Trae 软件的 UI 风格**——深色、专业、克制的 IDE 观感(VSCode 衍生质感),并要**代码追随**与 **HTML 预览**能力。取代 v0.7 蓝白科研皮。

## 气质
深色专业 IDE(像 Trae / VSCode Dark+ / Cursor):**深中性底 + 细边分隔 + 克制留白 + 信息密度高 + 一个精致克制的强调色**。扁平、锐利、工程感,不要圆润糖果色、不要玻璃拟态花哨、不要浅色学术。低调高级,像专业开发工具。

## 色板(深色,统一)
- `--bg`: #17171b(应用最底 / 活动栏)
- `--editor`: #1e1e22(编辑器/主内容区,略亮于 bg)
- `--panel`: #202024(侧栏/面板)
- `--elevated`: #26262c(弹层/hover)
- `--border`: #2c2c33;`--border-soft`: #242429
- 文字:`--fg` #e6e6ea、`--fg-2` #b4b4be、`--muted` #8a8a95、`--dim` #63636e
- **强调(Trae 感,克制的紫蓝)**:`--accent` #8b7cff(柔紫);hover #9a8dff;active #7a6bf0;`--accent-soft` rgba(139,124,255,0.14)(选中底/高亮)。可选签名渐变 `linear-gradient(120deg,#8b7cff,#5b8cff)` 仅用于极少数品牌点(logo/主按钮)。
- 语义:running/info #5b8cff、success #3fb950、warning #d29922、error #f85149(GitHub 深色语义色系,专业)。
- diff:增 #2ea04326 底/#3fb950 字,删 #f8514926 底/#f85149 字(IDE diff 配色)。

## 形状/密度/质感
- 圆角**收紧**:面板/卡 8、按钮 6、输入 6、chip 5、极小元素 4。比之前小,IDE 锐利感。
- 阴影几乎不用(IDE 靠边框分层);弹层用 `0 8px 28px rgba(0,0,0,.5)` + 细边。
- 边框主导分隔(1px `--border`);hover 用 `--elevated` 底或 `--accent` 边。
- 信息密度提高:行高紧一点、控件小一号(专业工具感),但仍可读。
- 无发光/无弥散光/无 aurora/无糖果多彩——这些都是"AI 化"来源,去掉。

## 字体
- UI:`Inter` / `-apple-system` / 思源黑体 / 微软雅黑,13-14px 基准(IDE 偏小)。
- 代码/终端/路径/token 数字:等宽 `"JetBrains Mono", ui-monospace, Consolas`。
- Monaco:改用**深色 IDE 主题**(VSCode Dark+ 风:底 #1e1e22、当前行 #2a2a31、关键字紫蓝、字符串 #a5d6a7、注释 #6a9955、行号 dim)。取代之前的浅色 agentboard-light。

## 布局(向 IDE 靠)
- 左侧栏做成**活动栏 + 侧边栏**观感(窄图标条 + 可折叠面板),导航项用图标 + 选中态左侧强调条(VSCode 式)。
- 顶栏细、扁,类标题栏;状态信息(账号/引擎/token)放底部**状态栏**(VSCode 底栏那种细条,深底、小字、分段)。
- 工作台(Workbench)本就是三栏 IDE,重点把它打磨到最像 Trae:文件树/编辑器 tab/终端面板/AI 对话都走 IDE 配色与密度。

## 落地范围(M3a 本任务:全站深色 IDE 重皮)
1. Tailwind 主题换成上面深色 token(替换蓝白别名);index.css 基础层重写(深底、细边工具类、去发光/去弥散、状态栏样式、IDE 滚动条);Monaco 深色主题。
2. ui 组件(Button/Card/Chip/StatusDot/Panel)改深色 IDE 质感(小圆角、细边、扁平)。
3. 全站页面逐一重皮:Layout(活动栏+侧栏+底部状态栏)、Board、StudioChat、StudioGen、Artifacts、Research、Market、Dashboard、Sediment、Settings、Login、Workbench 及其子组件、Canvas、ModelPicker、Composer、各面板。逐页查无"浅底残留"、对比度达标。
4. logo 仍用 φ,但配色贴 accent 紫蓝(深底上)。

## M3b(后续任务,不在本次)
- **代码追随**:工作台里 AI 改文件时,编辑器自动打开该文件 + 滚动到 + 高亮改动区域(跟随 AI 编辑,像 Cursor/Trae)。
- **HTML 预览**:工作台里打开 .html/.md 文件时,提供实时预览面板(iframe/渲染),编辑即刷新。

## 约束
- 深色为默认且唯一(本期不做浅色切换)。只改视觉/布局观感,不改业务逻辑/store/命令/路由;A/B/账号/市场/仪表盘等功能不得回退。
- 可读性:深底浅字对比达标(fg on editor ≥ 7:1)。中文文案不变。无 BOM UTF-8。
